# SimpleRemover
So sometimes we just hate having too much friends and the process of unfriending everyone takes CENTURIES
That's why i made SimpleRemover

# How to use
- Download the remover.js
- In the USER1 USER2 and USER3 replace it with the friends u would like to keep (username)
- Copy the code press Ctrl + Shift + I and then paste the code in the console
- Click ok
- It will start removing all ur friends except of the ones u put in keep

One thing that i wanna say is that u will get rate limited just keep pasting the script and stuff
